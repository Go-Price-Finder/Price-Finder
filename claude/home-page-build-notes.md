## Compliance gate — blocks non-compliant partners from import and display (2026-07-26)

Built the hard-requirement compliance gate: no partner's products ever import or display unless they've passed AWIN terms review, enforced in two independent places against one registry.

- **`lib/partner-compliance.json`**: single source of truth, one entry per partner (active or not) — `brooklyn-delhi`, `evdance`, `golden-maple` (all `active`), plus five reviewed-but-not-yet-applied partners (`aaawave`, `dignity-lifts`, `alorair-crawlspace`, `energy-muse`, `advanced-clinicals`, `beautyologie-caire-beauty`) with their specific restrictions recorded (image permission, plagiarism rules, excluded SKUs, medical-claims restrictions, price-sync sensitivity, discount-language restrictions, etc.) exactly as specified.
- **`lib/partner-compliance.ts`**: the shared gate logic. `checkImportGate()` implements the three hard blockers — no registry entry, `status` not `"active"`, or `comparisonEngineConfirmed: false` — any one blocks entirely. `canShowRealImages()`, `requiresDescriptionReview()`, and `requiresPerSkuFeatureCheck()` implement the three softer per-partner restrictions.
- **`scripts/import-partner.mjs`**: now runs the compliance gate first, before any CSV parsing or file writes — prints a full compliance report (passed / restrictions / blocked, with reasons) and exits with nothing written if the partner fails the hard gate. If it passes but has restrictions: image download is automatically skipped when `imageUsagePermission: "pending"` (with an explanation of why), and every product description is checked against the raw feed text for `noPlagiarism` partners, flagging close/verbatim matches for manual rewrite in both the console report and the end-of-run "still needed" checklist.
- **`lib/partners.ts`**: the render-time backstop — `PARTNERS` (the one list every homepage section, partner page, category page, and search query reads from) is now `ALL_WIRED_PARTNERS` filtered through `isPartnerLive()`. This closes the gap where a partner's data file could exist and be wired in (by hand, or because its status changed after import) without actually being compliant — the site itself refuses to return its products regardless of how it got into the codebase. Image gating (`imageUsagePermission: "pending"` → every real photo replaced with a new placeholder image, `public/images/_placeholders/image-pending.png`, generated for this purpose) happens inside `normalizeProduct()`; per-SKU gating (`excludedProducts: true` → excluded from Best Sellers/Deals) happens inside `getFeaturedDeals()`/`getBestSellers()`.
